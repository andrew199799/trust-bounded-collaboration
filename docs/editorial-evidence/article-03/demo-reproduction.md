The README's exact virtual-environment and isolated-build path was **not fully reproduced**. `python -m venv .venv` failed during `ensurepip` under this sandbox's Unicode/long Windows path; isolated `python -m build` encountered temporary-path and permission errors. Moving the source to a shorter local path and using `--no-isolation` allowed a package build and independent wheel run. These environment failures are not evidence that the TBC evaluator failed. The separate wheel run is evidence of the packaged CLI in this one environment, not a cross-platform or production test.

An anticipated `DENY` is a passing demonstration when the named fixture expects denial; each script exited 0 and none executed a real delete, merge, release or publication. The `approval_bound_action` fixture demonstrates the exact-action distinction: `approved_action` is `ALLOW`, while `changed_action_old_grant` is `DENY` with `ACTION_BINDING_MISMATCH`. Its `delete-document` transition name is a synthetic proposal, not a performed deletion.
